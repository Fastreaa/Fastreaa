## Applied AI

Projects where I integrate language models into real workflows, not just demos.

<p align="center"><img src="src/rot-ai.svg" width="100%" alt="What my AI projects do"/></p>


| Project | What it does | Stack |
|---|---|---|
| **LLM-powered automation** | Pipelines that use language models to read, classify and extract structured data from unstructured text, reducing manual review work. | Python · LLM APIs · SQL |
| **Document Q&A (RAG)** | Retrieval-augmented assistant that answers questions over a document collection, citing the source passages it used. | Python · Embeddings · Vector search |
| **AI agents with tools** | Assistants that call APIs and databases to complete multi-step tasks, with validation on every step. | Python · REST APIs · Tool calling |
| **AI-built web apps** | Web interfaces that put model capabilities behind a clean, usable UI. | React · Next.js · Vercel |

**Approach:** structured outputs, input validation, prompt evaluation, and keeping sensitive data out of model calls.

## How I Build

<p align="center"><img src="src/rot-principles.svg" width="100%" alt="Principles"/></p>

- **Maintainability:** clear code, modular design and separation of concerns.
- **Right-sized architecture:** abstractions that match the complexity of the problem.
- **Data integrity:** validation, consistency and traceability.
- **Security & privacy:** least privilege, secure configuration and care with sensitive data, especially around AI.
- **Automation:** reproducible workflows that reduce manual effort and errors.
